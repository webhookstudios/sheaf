# Sheaf 1.2.2

A bigger app icon, and an easier-to-find tab bar color.

- The app icon is bigger, so it sits evenly with your other apps in the dock and the app grid.
- In Settings, the tab bar color is now called "Tab bar background", and each color says what it colors. The colors you pick stay through restarts and updates.

Install:

```bash
sudo apt install ./sheaf_1.2.2_all.deb
```
